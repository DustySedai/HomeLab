## Firewall

The firewall was designed with restrictive default policies and explicit rules for required services.

The configuration included:

- Loopback traffic.
- Established and related connections.
- Invalid packet handling.
- SSH from the LAN.
- ICMP echo from the LAN.
- Nginx on TCP port `8080`.
- Uptime Kuma on TCP port `3001`.

Docker-managed firewall tables were taken into account when designing the rules.

## Security Approach

The firewall configuration followed a default-deny approach for incoming and forwarded traffic, with only required traffic explicitly allowed.

The purpose of each opened port was documented so that future changes could be reviewed rather than added without justification.
