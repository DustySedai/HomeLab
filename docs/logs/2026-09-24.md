## Project Documentation

A new daily logging system was defined for the homelab.

Daily logs will be stored under:

`docs/logs/`

Each log will use the date as its filename:

`YYYY-MM-DD.md`

The purpose of the logs is to record:

- What changed.
- Why the change was made.
- Commands or configuration involved.
- Results.
- Problems and troubleshooting.
- Notes and future work.

The daily logs complement the main documentation.
