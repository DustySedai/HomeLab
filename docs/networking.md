# Networking

## Local Network

The homelab server is connected to the local network through Wi-Fi.

### Server Network Configuration

| Parameter | Value |
|---|---|
| Interface | `wlp2s0` |
| IPv4 address | `192.168.100.X/24` |
| Gateway | `192.168.100.X` |
| Connection | Wi-Fi |

## Remote Administration

The server is administered remotely using SSH over the local network.
