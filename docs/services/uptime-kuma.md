# Uptime Kuma

## Overview

Uptime Kuma is a self-hosted monitoring service used to monitor the availability of services and network endpoints.

It provides a web interface for monitoring the status of services and receiving notifications when a monitored service becomes unavailable.

## Docker

Uptime Kuma runs as a Docker container.
